# Mailstone — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning, doing, looking up and understanding are four different needs, so they get four kinds of pages. Mailstone's documentation has two so far; the other two would only repeat the [README](https://github.com/johannes-kaindl/mailstone/blob/main/README.md), which already carries the settings tables and the "How it works" section.

**New here?** → [Getting started](getting-started.md) — from installation to your first mail note.

**Something not working?** → [Troubleshooting](how-to/troubleshooting.md) — the messages Mailstone shows, what causes them, what to do, and where to get help.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. One guided run-through: install, import a mail without any account, connect your mailbox, sync. |
| **[Troubleshooting](how-to/troubleshooting.md)** | Task-oriented. "The server rejected the login" — now what? Also: what happens offline, and what mobile can and cannot do. |

Everything else in this folder (`SMOKE.md`, the dated notes, `superpowers/`) is maintainer material, not user documentation.
